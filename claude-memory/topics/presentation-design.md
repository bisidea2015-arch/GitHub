description: "Тёмный фирменный стиль презентаций (кобальт-графит + терракота/оранж), который Павел просил использовать и в других презентациях"
---

- просил запомнить дизайн, разработанный для презентации [[triniguard-partnership]], и использовать его в других презентациях
- дизайн: фон — градиент кобальт → графит на весь слайд, поверх — приглушённый водяной знак логотипа компании
- акцентные цвета — терракотовый (основной) и оранжевый (вторичный, вместо жёлтого/золота)
- шрифты — Poppins для заголовков, Arial для основного текста
- карточки — тёмные панели с тонкой оранжевой обводкой; в углу слайда — диагональный геометрический акцент для динамики
- иконки — логотип компании в круглом бейдже с оранжевой обводкой вместо сторонних иконок
- маркированные списки — нативные буллеты (не ручные фигуры), чтобы точка и текст были на одной линии
- графики — горизонтальные бар-чарты в акцентном цвете на тёмной панели вместо таблиц с цифрами
- логотип компании — в футере на каждом слайде
- подтвердил, что этот тёмный стиль ему очень нравится — просил использовать его по умолчанию для всех своих презентаций
- занимается искусственным интеллектом; просил по возможности использовать в оформлении презентаций визуалы на тему ИИ
