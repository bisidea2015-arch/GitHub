- Павел договорился о бартерном сотрудничестве от лица АБИТ РосНОУ с компанией Тринигард (triniguard.ru, кибербезопасность, услуга MXDR)
- условия бартера: Павел/АБИТ занимаются продвижением рекламы Тринигард, взамен Тринигард берёт студентов АБИТ РосНОУ на практику
- план продвижения на первые 3 месяца: Яндекс.Бизнес → Яндекс.Директ → контент (Дзен, Telegram) → соцсети
- Павел делал для Тринигарда сайт (план продвижения) и теперь делает новый корпоративный сайт по их ТЗ и брендбуку
