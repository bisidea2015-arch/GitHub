- проект «Против ветра» придуман Павлом вместе со студентами; занимается арендой водной техники
- первый клиент планируется на Истре — техника для реки и озера
- формат — приложение/CRM для приёма заявок на аренду; покупатели приложения смогут заносить свою моторную технику и сдавать её в аренду
- хочет понять, как сам будет зарабатывать на приложении
- есть логотип: катер в круге с волнами, надпись «Против ветра!», подпись «Аренда водной техники»; цвета — тёмно-синий и бирюзовый; дизайн приложения хочет в стиле логотипа, с волнами, анимацией, градиентами и подсветкой
- решил продавать CRM-систему «Против ветра» яхт-клубам — нужен продающий лендинг для яхт-клубов
