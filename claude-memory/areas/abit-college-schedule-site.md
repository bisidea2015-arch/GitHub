- делает интерактивное расписание колледжа АБиТ РосНОУ для студентов и для себя (журнал, свои пары); размещает на Рег.ру (Host-Lite) на домене zelschoolabit.online
- у преподавателей единый общий пароль входа; хочет, чтобы выбранный преподаватель запоминался в браузере
- при входе по паролю — выбор «Кто вы?»; преподаватель видит только свои группы и предметы, администратор (Крутова О.М.) — всё; смена преподавателя только через новый вход
- из Мафии вход преподавателя (админка) убран совсем
- хочет в дневнике вкладку «ДЗ» для преподавателей (ДЗ по группам с файлом) и рассылку важных объявлений студентам с push-уведомлениями; вкладка «Мафия» — после «Кинозала» (см. [[abit-mafia-game]])
