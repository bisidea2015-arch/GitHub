## Что лежит в этой папке

Статическое зеркало публичного сайта (HTML + `_next/static`), скачанное с продакшена **2026-11-19**.

Это **не** исходники Next.js (нет `package.json`, `app/`, компонентов).  
Для правок контента/вёрстки на хостинге — правим файлы здесь и выкладываем ZIP на Рег.ру.  
Для глубокой разработки — нужен настоящий исходный репозиторий Next.js (пока не найден).
